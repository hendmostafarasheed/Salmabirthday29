SALMA'S ROYAL BIRTHDAY INVITATION — ENHANCED 3D VERSION

CONTENTS
- index.html: upgraded responsive invitation with floating/rotating playing cards, animated gold crown, deep 3D title, magical sparkles, dimensional details panels, raised interactive buttons, section transitions, RSVP preview, and guestbook preview.
- index-previous.html: preserved copy of the previous version.
- assets/birthday-song.mp3: the supplied birthday song.

PUBLISH ON GITHUB PAGES
1. Extract this ZIP on your computer or phone.
2. Create a repository on GitHub (or open your existing repository).
3. Upload index.html and the assets folder to the repository root. Keep assets/birthday-song.mp3 at that exact path.
4. Open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose the main branch and /(root), then Save.
6. Wait for deployment and open the URL shown in Settings → Pages.

MUSIC
The music starts after the visitor taps “Open the Invitation”, because browsers normally block autoplay with sound. The same audio element remains mounted when switching between the cover and details, so playback continues from its current position rather than restarting. The celebration page has a play/pause control.

BEFORE SHARING
- Update the event date and time in index.html (currently placeholder/demo details are present).
- Confirm the venue and map link.
- Replace the sample photo/video links with the real album and video links.
- RSVP and guestbook are demo-only: they show feedback in the visitor's browser but do not send/store responses for the host. Connect a form service or backend if you need online submissions.

MOBILE & ACCESSIBILITY
The layout adapts to narrow screens. Users who enable reduced motion on their device receive reduced animations.
